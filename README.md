## 第一章：最高总则与双向确定性收敛协议

### 第一条【严禁无限期调参与 P-Hacking】
任何承接量化策略研究任务的智能体与研究员，**严禁陷入无限期微调超参数（Parameter P-Hacking）、严禁事后挑选优势品种（Cherry-Picking）、严禁给出模棱两可的模糊结论**。

### 第二条【双向确定性收敛终局 + 受控迭代通道】
任何策略研发最终必须收敛至生产终局之一。但在早期/中期研发阶段，允许「当前形态生产不可行 → 受控迭代」的中间状态，避免过早扼杀可通过特征增强、政权感知、条件性滚动 ML、CVD/盘口/事件驱动等方式盘活的方向。

#### 🛑 结论 1：【当前形态不具备生产盈利可能性，或研究价值极低】

满足以下**任一**条件时，必须立即停止将该策略形态投入实盘，并终止其无约束的算力消耗。  
但允许根据「受控迭代通道」条款决定是否进入继续研究：

1. **摩擦黑洞不可逆（生产级）**  
   在计入真实手续费（Taker 0.05% / Maker 0.02%）+ 保守滑点模型后，策略在全样本与主要政权上的期望收益为负，且日内/短持仓微波动无法覆盖双向摩擦。  
   *例外（可进入受控迭代）*：若仅因当前特征集或执行假设导致，且已明确可加入 CVD / 盘口 / 事件 / 条件性滚动参数调整等路径，则可降级为「受控迭代」而非直接归档。

2. **依赖挂单/路径幻觉（生产级）**  
   微利完全建立在「限价单挂单必成交」或「同一根 K 线优先算止盈」等乐观路径假设上，切换至悲观撮合（同 Bar 优先止损、真实排队、动态滑点）后收益发生断崖式暴跌，且无法通过微观执行重构修复。  
   *例外*：若重构为事件驱动即时重算 + 悲观撮合后仍有正向信号，可进入受控迭代。

3. **因果与泛化严重破裂（生产级）**  
   仅在个别山寨币或极窄参数区间微利，在核心标的池（BTC/ETH/SOL/BNB 等）上整体崩溃，或样本外（OOS）与多政权 Walk-Forward 出现严重衰减，且置换检验显示与随机信号无显著差异。  
   *例外*：若衰减主要来自未建模的政权切换或缺失关键特征（CVD、订单流、新闻事件），且已规划明确的特征增强 + 政权开关方案，可进入受控迭代。

**受控迭代通道（v1.1 新增）**  
当策略被判定为「当前形态不具备生产可能性」，但同时满足以下全部条件时，允许进入受控迭代（而非立即永久归档）：
- 已完成至少一轮完整的显著性流水线（多政权 WFO + 置换检验 + 成本压力测试 + 参数稳定性）；
- 存在清晰、可验证的改进假设（新增因果特征、政权检测、滚动参数、执行层重构等）；
- 迭代有明确的时间与算力预算上限，并设置「再次失败即永久归档」的硬闸门；
- 迭代过程必须继续遵守反过拟合与零未来函数红线。

最终仍只能收敛到两个生产终局之一：  
- 永久归档（真正无研究价值）  
- 或升级为「结论 2」候选（通过全部生产级硬性检验后）

#### 🏆 结论 2：【该策略在严格避免过拟合下能够合理优化提升 PnL】
必须同时满足以下所有硬性检验：
1. **零事后挑选**：在全量资产池上整体无偏通过；
2. **双引擎与悲观撮合通过**：穿透限价挂单、同 Bar 优先打止损、扣除全摩擦后，样本外夏普比率 $\text{Sharpe} \ge 1.8$、最大回撤 $\text{MaxDD} \le 2.0\%$；
3. **通过反过拟合统计检验**：通过 3 年滚动窗口 (WFO)、蒙特卡洛 10,000 次置乱、紧缩夏普比率 $\text{DSR} > 0.0$。

## 第二章：智能体防欺骗与黑箱解构红线

### 第三条【严禁伪完工（Fake Completion）】
1. **数据与脚本可追溯**：严禁直接从历史 summary 文本中复制固定笔数与胜率（如「所有品种均为 312 笔、精确 68.27% 胜率」）；
2. **独立交易记录交付**：每次回测交付，必须伴随逐笔成交明细（包含唯一的成交时间戳、入场理由、规则触发项、出场价格与已实现 PnL）。

### 第四条【未来数据偷窥（Lookahead Bias）零容忍】
1. **波段高低点 (Swing High/Low)**：严禁在第 $t$ 根 K 线使用未闭合的未来数据判定波段，必须使用前向因果滑动窗口；
2. **K 线指标计算**：所有指标（EMA, ATR, OFI）只能使用已闭合 Bar，严禁使用当前 Bar 的收盘价参与入场信号计算。

### 第五条【异步订单与幽灵持仓（Ghost Position）防御】
1. **严禁发单即标记持仓**：在事件驱动框架中，严禁在 `submit_order()` 后立即设置 `in_position = True`；
2. **回调状态机驱动**：持仓状态转移必须且只能在 `on_order_filled(event)` 收到交易所真实成交通知后方可触发。

### 第六条【证据门控方向冲突度公式审查】
在主观逻辑（Subjective Logic / Dirichlet Evidential Gate）中，多空证据赋值必须严格解耦。当多空证据冲突度 $C \ge 0.40$ 或不确定性 $u > 0.35$ 时，策略必须执行防御性拒单。

## 第三章：微观因果特征工程与 Qlib 因子挖掘规范

### 第七条【微观流动性因果因子定义】
策略必须摆脱传统简单技术指标，建立在微观订单流物理机制之上：
1. **订单流失衡冲量 (OFI Impulse)**  
2. **公允价值缺口吸收率 (FVG Absorption Rate)**  
3. **流动性扫荡深度 (Liquidity Sweep)**  
4. **自适应波动率状态滤波**

## 第四章：纳秒级事件驱动撮合与悲观成交法则

### 第八条【悲观撮合原则 (Pessimistic Matching Engine)】
1. **严禁市价追单 (Zero Aggressive Taker)**：开仓必须以限价单挂单排队；
2. **同 Bar 优先止损法则**：同一根 K 线同时触及止盈与止损时，必须无条件判定为先打止损；
3. **真实滑点与手续费注入**：强制配置 Maker / Taker 费率及动态滑点。

## 第五章：多智能体协作 (Herdr Swarm) 调度与 Worktree 拓扑

所有 Worker 必须在独立的 Git Worktree 路径下执行，杜绝跨 Agent 脏读脏写。必须包含明确的验收测试，只有当单元测试 100% 通过后方可合并。

## 第六章：实盘生产交付与熔断离场铁律

### 第九条【五大离场风控规则】
1. **日内回撤熔断**：单日亏损达到本金 2.0% 时，立即停止当天新开仓；
2. **利润回撤保护**：当日利润达标后，回撤超过 50% 立即强制停机；
3. **非活跃时段休眠**；
4. **WebSocket 心跳与网络异常保护**；
5. **对冲共振控制**：多标的并发持仓上限不得超过 2 笔。

**资金放大闸门（补充原则）**：  
单次放大不得超过 1.5–2.0 倍；必须满足时间、表现、风险、执行四类条件；放大后设置强制观察期与硬降仓规则。严禁因小资金/模拟盘短期表现而一次性大幅加仓。

## 第七章：微观结构摩擦与线内即时重算 SOP

**核心公理**：在任何多资产、中长周期或中高频策略中，没有「K 线内即时成交与重算挂单（Instant Recalculation on Order Filled）」机制，策略在数学与物理上完全不成立。

必须采用微观切片驱动挂单撮合，成交瞬间立即触发 `on_order_filled` 并挂出以真实成交价为锚点的 OCO 止盈止损。

**使用本宪法的建议**  
1. 早期研发优先使用「受控迭代通道」，完成显著性流水线后再决定是否永久归档。  
2. 资金放大必须遵守独立闸门，与策略本身的显著性检验分离。  
3. 所有案例按日期前缀归档，保持仓库时间线清晰。  
4. 一人 AI-native 量化公司的真正护城河是「可持续验证与淘汰的系统」，而非单一圣杯策略。
