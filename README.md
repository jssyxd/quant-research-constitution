## 第一章：最高总则与双向确定性收敛协议

### 第一条【严禁无限期调参与 P-Hacking】
任何承接量化策略研究任务的智能体与研究员，**严禁陷入无限期微调超参数（Parameter P-Hacking）、严禁事后挑选优势品种（Cherry-Picking）、严禁给出模棱两可的模糊结论**。

### 第二条【双向确定性收敛终局】
任何策略研发必须且只能收敛至以下两个互斥结论之一，作为研发任务的物理终点：

#### 🛑 结论 1：【该策略没有研究价值，在任何情况下都不具备生产盈利可能性】
满足以下任一条件时，**必须立即终止该策略的算力消耗，坚决不允许进入实盘**：
1. **摩擦黑洞不可逆**：计入真实手续费（Taker 0.05% / Maker 0.02%）与滑点后，策略期望收益为负，日内高频微波动无法覆盖双向交易摩擦；
2. **依赖挂单/路径幻觉**：微利完全建立在“限价单挂单必成交”或“同一根 K 线优先算止盈”的路径假设上，切换至悲观撮合后收益发生断崖式暴跌；
3. **因果与泛化破裂**：仅在个别山寨币或单一特定参数上微利，在全量适用标的池（BTC/ETH/SOL/BNB）上崩溃，样本外（OOS）严重衰减。

#### 🏆 结论 2：【该策略在严格避免过拟合下能够合理优化提升 PnL】
必须同时满足以下所有硬性检验：
1. **零事后挑选**：在全量资产池上整体无偏通过；
2. **双引擎与悲观撮合通过**：穿透限价挂单、同 Bar 优先打止损、扣除全摩擦后，样本外夏普比率 $\text{Sharpe} \ge 1.8$、最大回撤 $\text{MaxDD} \le 2.0\%$；
3. **通过反过拟合统计检验**：通过 3 年滚动窗口 (WFO)、蒙特卡洛 10,000 次置乱、紧缩夏普比率 $\text{DSR} > 0.0$。

## 第二章：智能体防欺骗与黑箱解构红线

### 第三条【严禁伪完工（Fake Completion）】
1. **数据与脚本可追溯**：严禁直接从历史 summary 文本中复制固定笔数与胜率（如“所有品种均为 312 笔、精确 68.27% 胜率”）；
2. **独立交易记录交付**：每次回测交付，必须伴随逐笔成交明细（包含唯一的成交时间戳、入场理由、规则触发项、出场价格与已实现 PnL）。

### 第四条【未来数据偷窥（Lookahead Bias）零容忍】
1. **波段高低点 (Swing High/Low)**：严禁在第 $t$ 根 K 线使用未闭合的未来数据判定波段，必须使用前向因果滑动窗口（如严格要求确认回撤后方可定点）；
2. **K 线指标计算**：所有指标（EMA, ATR, OFI）只能使用已闭合 Bar，严禁使用当前 Bar 的收盘价参与入场信号计算。

### 第五条【异步订单与幽灵持仓（Ghost Position）防御】
1. **严禁发单即标记持仓**：在事件驱动框架（NautilusTrader / 实盘）中，严禁在 `submit_order()` 后立即设置 `in_position = True`；
2. **回调状态机驱动**：持仓状态转移必须且只能在 `on_order_filled(event)` 收到交易所真实成交通知后方可触发，杜绝挂单未成交导致后续市价平仓变成裸反向开仓。

### 第六条【证据门控方向冲突度公式审查】
在主观逻辑（Subjective Logic / Dirichlet Evidential Gate）中，多空证据赋值必须严格解耦：
```python
# 严禁以下导致冲突度 C 恒等于 1.0 的致命 Bug:
# bull_ev = score / 10 if dir == 1 else score_short / 10
# bear_ev = score / 10 if dir == -1 else score_long / 10

# 正确标准实现:
bull_ev = max(0.0, score_long / 10.0)
bear_ev = max(0.0, score_short / 10.0)
```
当多空证据冲突度 $C \ge 0.40$ 或不确定性 $u > 0.35$ 时，策略必须执行防御性拒单。

## 第三章：微观因果特征工程与 Qlib 因子挖掘规范

### 第七条【微观流动性因果因子定义】
策略必须摆脱传统简单技术指标，建立在微观订单流物理机制之上：
1. **订单流失衡冲量 (OFI Impulse)**:
   $$\text{OFI}_t = \frac{\text{Close}_t - \text{Low}_t}{\text{High}_t - \text{Low}_t + \epsilon} \times \left(\frac{\text{Volume}_t}{\text{SMA}(\text{Volume}, 20)}\right)$$
2. **公允价值缺口吸收率 (FVG Absorption Rate)**:
   实时跟踪价格回踩至相邻 3 根 K 线的真空区中轴（50% 平衡线）时的量能衰竭；
3. **流动性扫荡深度 (Liquidity Sweep)**:
   以因果滑动窗口计算影线击穿关键流动性池的瞬时深度；
4. **自适应波动率状态滤波**:
   仅在 $0.55 \le \frac{\text{ATR}(14)}{\text{ATR}(100)} \le 1.80$ 活跃动量通道内激活。

### 第八条【悲观撮合原则 (Pessimistic Matching Engine)】

## 第六章：实盘生产交付与熔断离场铁律 (Walk-Away Rules)

### 第九条【五大离场风控规则 (5 Walk-Away Rules)】
1. **日内回撤熔断**：单日已实现或浮动亏损达到本金的 $2.0\%$ 时，立即停止当天所有新开仓；
2. **利润回撤保护**：当日利润达标后，一旦利润回撤超过 $50\%$，立即强制停机锁定利润；
3. **非活跃时段休眠**：在流动性真空与跨市场交接垃圾时段，禁止发起任何新开仓；
4. **WebSocket 心跳与网络异常保护**：一旦失去交易所行情心跳超过 15 秒，撤销所有活动挂单，冻结开仓权限；
5. **对冲共振控制**：多标的池共享资金池并发持仓上限不得超过 2 笔，杜绝全仓位同向暴跌共振。
