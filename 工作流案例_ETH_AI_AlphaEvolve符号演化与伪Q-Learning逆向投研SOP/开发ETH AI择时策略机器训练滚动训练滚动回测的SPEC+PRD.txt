# 第一部分：产品需求文档 (PRD, Product Requirement Document)

## 1. 执行摘要与项目愿景

### 1.1 背景与现状剖析
007 号策略 `ETH_AI_Timing_AlphaEvolve_15m` 是一套基于 Google AutoML-Zero / AlphaEvolve 神经引导演化范式构建的以太坊 15 分钟级别 AI 择时系统。在研发前期，该系统通过遗传规划（GP）自动组合抽象语法树（AST），并依靠施加了极端回撤平方惩罚项的适应度函数，自发演化出了带有折扣因子 $\gamma$ 与学习率 $\alpha$ 的时间差分（TD-like）状态价值打分结构（Q-State）：
$$V(t) = \gamma \cdot V(t-1) + \alpha \cdot R_{\text{step}}(t)$$
在 2026 年 10 月初的 30 天实盘对齐回测与 OKX 信号交易广场中，该策略取得了高达 92.31% 的平仓胜率、22.94% 的累计收益率以及 3.42 的年化夏普比率。

**然而，在穿透式的中长周期全量数据回测中，该系统暴露出量化策略普遍面临的致命瓶颈：**
1. **中周期（131天，2026-06-01 至 2026-10-09）**：净值录得 -23.52%，最大回撤达到 26.45%，盈亏比骤降至 1.31。
2. **全周期（365天，2025-10-20 至 2026-10-20）**：净值录得 -66.51%，最大回撤高达 70.78%，盈亏比恶化至 0.831（负期望值）。

穿透式审计清晰地表明：**该策略的底层胜率具备极强的结构稳健性（全样本 1,141 笔交易中仍录得 73.79% 的胜率），但其单笔盈亏结构存在非对称的“小赚大亏”特征（平均盈利 +38.55 USDT，平均亏损 -130.62 USDT，赔率仅为 0.30）。** 当市场遭遇单边流动性踩踏或长期趋势单边延伸时，固定参数的静态 AST 符号树会发生严重的**概念漂移（Concept Drift）**与**宏观机制跃迁（Regime Shift）失效**。原有的微观极值通道被持续击穿，导致马丁二次加仓（75%）拉大敞口后触及 2.50% 硬止损，一次极端亏损吞噬掉数笔剥头皮累积的全部利润。

### 1.2 愿景与核心使命
为了解决“静态策略必死”的工业宿命，本项目确立核心愿景：**将 007 策略从一个“静态规则运行器”重构为具备“自主感知、自适应滚动重训、双引擎独立校验、多级安全熔断与自动化 CI/CD 交付”的工业级自愈量化闭环系统。** 

项目借鉴 Two Sigma、Jane Street、AQR 等全球顶级量化基金的动态因子重估机制，引入动态 Walk-Forward 滚动分析、在线漂移监控哨兵与事件驱动热更新通道，确保交易程序在宏观机制发生跳变时能自动收缩敞口、触发云端算力重训并平滑切换策略内核。

## 2. 外部优秀资产与工业界标杆案例调研评估

针对用户提出的外部成体系路径与业内经典机器学习工业实践，我们结合 `kaggle-cli`、`huggingface_hub` 与 `gh cli` 的工程生态，进行深度评估与复用路径规划。

### 2.1 业界优秀开源方案评析

#### 2.1.1 AKQuant 机器学习与时序回测体系 (`akfamily/akquant`)
- **核心理念**：`akquant` 提供了轻量级的事件驱动回测框架，并重点探索了时序特征工程（Alpha158、Alpha360）与传统机器学习（Scikit-Learn、LightGBM）的拼接方式。其精髓在于**时序特征严格防未来信息泄露（No-Lookahead Bias）**以及基于滚动切片的交叉验证。
- **参考与复用价值**：
  - 其提供的统一时序特征标准化（Rolling Z-Score、RobustScaler）和数据管道模式，可以直接作为我们特征提取层的基准实现。
  - 局限性：`akquant` 的底层事件循环为纯 Python 实现，高频 Tick 或 15m 逐笔排队时吞吐量较低，无法承受数十万次遗传变异的快速评估。因此，我们将其“特征标准化规范”沉淀入系统，底层计算则依托 NautilusTrader 的 Rust/Cython 内核与 VectorBT Numba JIT。

#### 2.1.2 BigQuant 滚动训练与动态因子衰减研究 (`BigQuant Wiki`)
- **核心理念**：BigQuant 在其文档体系（`GyW8WAvzwS`、`xVqIPu6RoI`）中详细论述了**滚动训练（Walk-Forward Model）、动态权重衰减与市场状态自适应机制**。
  - **核心论点 1**：金融时序具有极高的非平稳性（Non-stationarity），静态训练集超过 6 个月必然出现泛化崩溃。模型必须采用“固定窗口滑动”或“扩张窗口（Expanding Window）”进行增量更新。
  - **核心论点 2**：因子 IC（Information Coefficient）与特征重要度（Feature Importance）随时间呈现明显的衰减曲线。当监控到 Rank IC 连续 N 期低于临界阈值或换手损耗超过 Alpha 边际时，系统必须自动触发权重重分配。
- **参考与复用价值**：
  - 这与 007 策略“每 90 天必须重新演化”的量化宪法完全吻合。我们将其“特征状态衰减打分器”直接整合进本项目的 L2 概念漂移哨兵模块中。

### 2.2 顶级平台优秀开源用例映射

为确保方案具备全球顶级开源生态的支撑，本项目在 Kaggle、HuggingFace 与 GitHub 上锚定以下工业级开源项目与高赞 Notebook，作为模块实现的对齐基准：

1. **Google AutoML-Zero 官方生态与符号演化 (`google-research/automl-zero`)**
   - **机制**：从最基础的指令集（Setup, Predict, Learn）演化出完整的学习算法。
   - **复用点**：吸收其随机突变算子设计与染色体内存表（Memory Cache）设计，作为本系统 `AlphaEvolve JIT` 算子池的底层演化逻辑。

2. **Kaggle 经典竞赛冠军方案：Ubiquant / G-Research Crypto Forecasting**
   - **精选 Notebook 案例**：
     - *LightGBM with PurgedGroupTimeSeriesSplit*: 严格剔除时序重叠和数据泄漏的滚动训练管道。
     - *Pure-NumPy Micro-Transformer*: 仅用 100 行纯 NumPy 编写的因果注意力机制（Causal Self-Attention），专为内存受限环境下的超低延迟因子推断设计。
   - **复用点**：沉淀为未来扩展模块（第十一部分），提供纯 NumPy 实现，摆脱笨重的 PyTorch 运行时。

3. **HuggingFace 时序与算法生成模型**
   - **模型引用**：`Qwen/Qwen2.5-Coder-7B-Instruct`、`DeepSeek-Coder-V2-Lite`。
   - **机制应用**：探索基于代码大模型的“LLM-Guided Mutation”（大模型引导演化）。在 GP 发生瓶颈（停滞在局部极值）时，提取表现前 5% 的 AST 语法结构作为 Prompt，调用大语言模型生成新颖且符合维度的变异算子，替代单纯的随机变异。

## 6. 特征工程数学模型与算子集规范

### 6.1 严格防未来信息的输入特征集 (Features)
所有特征必须在且仅在 $t$ 时刻 15m Bar 完全收盘确认时计算，严禁使用 $t+1$ 时刻的任何价格。

1. **对数收益率 (Log Return, `RET`)**:
   $$\text{RET}_t = \ln\left(\frac{C_t}{C_{t-1}}\right)$$
   平稳化价格序列，消除单边绝对价格尺度的影响。
2. **成交量变动加速度 (Volume Acceleration, `VOL_ACCEL`)**:
   $$\text{VOL\_ACCEL}_t = \frac{V_t - \text{SMA}_5(V)_t}{\text{SMA}_5(V)_t + \epsilon}, \quad \epsilon = 10^{-6}$$
   刻画微观成交量突发放大倍数，识别机构主力抢筹或抢跑行为。
3. **高低价相对振幅 (High-Low Spread, `HL_SPREAD`)**:
   $$\text{HL\_SPREAD}_t = \frac{H_t - L_t}{C_t + \epsilon}$$
   度量柱体内流动性冲击空间，作为波动率机制的瞬时代理变量。
4. **K 线收盘位置压力比 (Bar Pressure, `K_POS`)**:
   $$\text{K\_POS}_t = \frac{C_t - L_t}{H_t - L_t + \epsilon}$$
   反映 K 线内多空搏杀的最终胜负均势，值域严格限制在 $[0, 1]$ 之间。
5. **主动买卖盘失衡比 (Taker Imbalance, `TAKER_IMB`)**（仅在有主动吃单流接口时使用，实盘只读 OHLCV 时由 AST 树自动降级）:
   $$\text{TAKER\_IMB}_t = \frac{2 \cdot V_{\text{taker\_buy}, t} - V_t}{V_t + \epsilon}$$

### 6.2 符号演化算子池 (Primitive Set)
算子池设计严格遵循**闭包性（Closure Property）**与**强类型保护**，杜绝任何除零溢出、非数（NaN）与无限大（Inf）。

| 算子标识符 | 输入参数 | 确切数学定义 | 保护边界与说明 |
| :--- | :---: | :--- | :--- |
| `add` | $(x, y)$ | $x + y$ | 常规代数相加 |
| `sub` | $(x, y)$ | $x - y$ | 常规代数相减 |
| `mul` | $(x, y)$ | $x \cdot y$ | 常规代数相乘 |
| `safe_div` | $(x, y)$ | $\begin{cases} x / y, & |y| > 10^{-5} \\ 1.0, & |y| \le 10^{-5} \end{cases}$ | 极小值截断保护除法，杜绝零除崩溃 |
| `ts_lag` | $(x, d=1)$ | $x_{t-d}$ | 严格时序向后滞后，绝无未来数据泄露 |
| `ts_delta` | $(x, d=1)$ | $x_t - x_{t-d}$ | 滚动时序一阶差分动量 |
| `ts_sma` | $(x, w=16)$| $\frac{1}{w}\sum_{i=0}^{w-1} x_{t-i}$ | 滚动简单移动平均 |
| `ts_zscore` | $(x, w=20)$| $\frac{x_t - \mu_{w,t}}{\sigma_{w,t} + \epsilon}$ | 滚动统计标准化（总体标准差计算） |
| `q_learning_node` | $(s, m, \kappa)$ | $V_t = 0.88 \cdot V_{t-1} + 0.12 \cdot (s_t \cdot 15.0 + m_t \cdot 0.8)$ | **涌现状态估值算子**：时间差分递归记忆 |

## 7. 动态滚动重训 (Walk-Forward Optimization, WFO) 核心引擎

### 7.1 WFO 滚动切片矩阵架构与 Purged & Embargoed 时序防泄漏隔离
为彻底消除过拟合与标签时间重叠泄露，策略拒绝任何全样本全局优化，严格基于机构级 **Purged Walk-Forward (P-WFO)** 架构进行动态参数与 AST 树演化：

- **训练切片窗口（In-Sample, IS）**：**25,000 根 15m K 线（约 260 天，8.5 个月）**，覆盖完整的牛熊转换与震荡区间。
- **清除缓冲区（Purge Buffer）**：**20 根 15m K 线（5小时）**。物理清除 IS 与 OOS 交界处跨窗口的标签重叠与回撤记忆，彻底阻断自相关前向信息穿越。
- **步进前瞻窗口（Out-of-Sample, OOS）**：**5,000 根 15m K 线（约 52 天，接近 2 个月）**，作为绝对物理隔离的盲测集。
- **禁运缓冲区（Embargo Buffer）**：**10 根 15m K 线（2.5小时）**。防止后向残余自相关渗透入后续迭代窗口。
- **步进滑动机制**：每次重训向前步进 5,000 根 K 线，循环往复推进。

```
Timeline: [----------------- 35,040 根 15m K线 (全样本一年) ----------------->]
Fold 1:   [==== 25,000 根 IS 训练 ====][P:20][== 5,000 根 OOS 盲测 ==][E:10]
Fold 2:         [==== 25,000 根 IS 训练 ====][P:20][== 5,000 根 OOS 盲测 ==][E:10]
Fold 3:               [==== 25,000 根 IS 训练 ====][P:20][== 5,000 根 OOS 盲测 ==][E:10]
```

### 7.2 演化目标优化函数（Fitness Formulation）
适应度函数是引导种群自然选择的核心 Reward 标量。为迫使算法压制回撤并自愈，设计如下多目标惩罚函数：

$$\text{Fitness}(Tree) = 1.5 \cdot \text{Calmar}_{\text{IS}} + 10.0 \cdot \text{WinRate}_{\text{IS}} - 15.0 \cdot (\text{MaxDrawdown}_{\text{IS}})^2 - \lambda \cdot \text{NodeCount}(Tree)$$

- **回撤平方惩罚项（$-15.0 \cdot \text{MDD}^2$）**：
  若策略回撤控制在 $5\%$，惩罚仅为 $-15 \cdot (0.05)^2 = -0.0375$；一旦回撤突破 $20\%$，惩罚激增至 $-0.60$；回撤达 $50\%$ 时，惩罚高达 $-3.75$（瞬间摧毁个体的适应度，使之成为负值而被锦标赛选择直接淘汰）。
- **奥卡姆剃刀长度惩罚（$-\lambda \cdot \text{NodeCount}$，取 $\lambda=0.01$）**：
  对公式树节点数量进行线性惩罚。在收益等价的前提下，包含 10 个节点的公式树彻底淘汰包含 30 个节点的臃肿公式，从数学结构上杜绝代码膨胀（Code Bloat）。

### 7.3 出厂四大准入门禁（Gatekeepers）与防过拟合检验 (DSR / PBO)
任何在 IS 上演化出的最优个体，必须在绝对物理隔离的 5,000 根 OOS 盲测数据上接受**全自动机器准入质检**：
1. **OOS 平仓胜率**：$\text{WinRate}_{\text{OOS}} \ge 75.0\%$，且平仓交易笔数 $\ge 15$ 笔。
2. **OOS 盈亏比与卡尔玛**：$\text{PF}_{\text{OOS}} \ge 1.25$ 或 $\text{Calmar}_{\text{OOS}} \ge 2.50$。
3. **OOS 最大历史回撤**：$\text{MaxDrawdown}_{\text{OOS}} \le 12.0\%$。
4. **统计防过拟合三重防御 (WFE / DSR / PBO)**：
   - **Walk-Forward 效率比率 (WFE)**：
     $$\text{WFE} = \frac{\text{Sharpe}_{\text{OOS}}}{\text{Sharpe}_{\text{IS}}} \ge 70.0\%$$
   - **减水夏普比率 (Deflated Sharpe Ratio, DSR)**（Bailey & López de Prado, 2014）：
     对多重测试假发现偏差（Selection Bias across $K$ trials）以及收益率非正态偏度 $\widehat{\gamma}_3$ 与峰度 $\widehat{\gamma}_4$ 进行统计惩罚，要求：
     $$\text{DSR} = \Phi \left( \frac{(\widehat{SR} - SR^*) \sqrt{N - 1}}{\sqrt{1 - \widehat{\gamma}_3 \widehat{SR} + \frac{\widehat{\gamma}_4 - 1}{4} \widehat{SR}^2}} \right) \ge 0.90$$
   - **回测过拟合概率 (Probability of Backtest Overfitting, PBO)**：
     组合对称交叉验证（CSCV）下，IS 优选模型在 OOS 表现劣于中位数的概率必须满足：
     $$\text{PBO} \le 15.0\%$$
只有四项大门禁指标全部变绿，CI/CD 流水线才允许将该模型推入准生产仓库。

### 7.4 严谨多维度消融实验体系 (Systematic Ablation Study Protocol)
在现代科学量化与机器学习中，策略性能必须通过**法医级消融实验（Ablation Study）**证明每一个模块的独立超额收益贡献（Alpha Contribution），彻底排除因模块偶然共振或数据窥探带来的虚假胜率。任何候选模型推向生产或进入实盘热备前，必须在标准 WFO 验证集与压力测试集上执行以下**六大维度全景消融隔离评测**：

```
                    【007 策略全要素基准架构 (Full Baseline Model)】
                     [AlphaEvolve AST + Q-State 递推 + 75%马丁加仓
                      + 动态追踪止盈 (+0.9%) + 2.5%硬止损 + 3.0x杠杆]
                                        │
      ┌─────────────┬─────────────┼─────────────┬─────────────┬─────────────┐
      ▼             ▼             ▼             ▼             ▼             ▼
  【消融组 A】   【消融组 B】   【消融组 C】   【消融组 D】   【消融组 E】   【消融组 F】
 剔除 Q-State   剔除二次加仓  剔除追踪止盈   剔除硬止损    杠杆归一消融   特征池正交
  (降为静态AST)  (单笔50%固定)  (改整点离场)   (无保护扛单)   (3.0x -> 1.0x)  (单因子孤立)
```

#### 7.4.1 消融变体设计矩阵与量化假设检验

1. **消融变体 A (Ablation-A: W/O Q-State Emergence - 剔除强化学习时间差分记忆)**
   - **操作方法**：将 AST 树中的强化学习算子 $V(t) = \gamma \cdot V(t-1) + \alpha \cdot R(t)$ 强行置换为普通无记忆时序差分 $\Delta(Price)$ 或静态动量阈值，其余风控参数完全冻结。
   - **理论假设**：Q-State 本质上充当低通滤波与动态信噪比门控。剔除 Q-State 后，模型在震荡假突破行情中的错误触发频率将激增 $\ge 35\%$，胜率从 $82\%+$ 坍塌至 $60\%\sim 65\%$，证实 Q-State 的涌现具有绝对真实的博弈过滤价值。

2. **消融变体 B (Ablation-B: W/O Margin Addition - 剔除 75% 可用保证金二次加仓)**
   - **操作方法**：完全禁用加仓状态机，每次开仓仅使用 50% 可用保证金，持仓直至出场（固定单笔仓位）。
   - **理论假设**：二次加仓利用了均价自愈机制，能拉低回踩成本加速触发 +0.90% 止盈；消融后虽然单笔极端亏损大幅收敛（杜绝单笔亏损扩大至 7% 净值），但平均平仓胜率会下降约 8%~12%，资金周转率降低，总累计收益率预计下降 40% 以上。

3. **消融变体 C (Ablation-C: W/O Intra-Bar Trailing TP - 剔除盘中动态追踪止盈)**
   - **操作方法**：取消盘中触及持仓均价 $+0.90\%$ 立即以 Taker 市价平仓的机制，改为等待 15m K 线完全闭合（Bar Close）且满足反向信号或固定收盘价止盈。
   - **理论假设**：15m 级别的加密货币高频市场中充斥大量“插针即回落”的做市商流动性踩踏。若放弃盘中瞬时动态止盈，大量原本已浮盈 0.90%~1.20% 的订单将在后续数分钟内被反包吐回，盈亏比与胜率将出现双重断崖式下跌。

4. **消融变体 D (Ablation-D: W/O Hard Stop-Loss - 剔除 -2.50% 均价硬止损)**
   - **操作方法**：移除 $-2.50\%$ 的撮合引擎强制止损，仅依赖反向反转信号或极端保证金维持率平仓（测试“死扛博反弹”假设）。
   - **理论假设**：在单边流动性枯竭（如 10-07 极端暴跌或 365 天中遇到的系统性下挫）行情中，消融该模块将直接导致最大历史回撤从 $11.8\%$ 暴增至 $60\%+$ 甚至爆仓穿仓，确立 $-2.50\%$ 硬止损作为底层“绝对生命线风控”的数学必要性。

5. **消融变体 E (Ablation-E: Leverage Sensitivity - 杠杆倍数剥离 3.0x vs 1.0x vs 5.0x)**
   - **操作方法**：在保持相同保证金比例（首仓 50%、加仓 75%）下，将名义杠杆分别设定为 1.0x（无杠杆基准）、3.0x（生产标准）与 5.0x（激进测试）。
   - **理论假设**：验证策略收益率是否仅仅依靠杠杆线性放大，还是源自底层正期望值（Alpha）。在 1.0x 下策略仍必须保持 Sharpe $\ge 1.20$ 且最大回撤 $\le 4.0\%$，证明策略具备纯粹的未加杠杆内生性超额收益。

6. **消融变体 F (Ablation-F: Feature Orthogonality - 特征池正交与单因子置换消融)**
   - **操作方法**：对输入特征池中的四大族群（趋势动量、均值回归、波动率度量、微观订单流失衡 OFI）分别采用 Permutation Feature Importance（置换特征置乱）与单族群剔除重测。
   - **理论假设**：量化输出各特征族群对最终 Fitness 的边际贡献率，若某一因子被置乱后模型胜率与回撤完全不变，则判定该因子为冗余噪音，从原始特征集规范中彻底剔除。

## 8. 双引擎对齐验证与结算规范 (VectorBT vs NautilusTrader)

### 8.1 为什么必须坚持双引擎独立对齐？
- **单一回测引擎的认知偏差**：
  - 纯向量化引擎（如 VectorBT / Pandas）速度极快，但容易在 K 线内部（Intra-bar）最高价/最低价先触及止盈还是止损的问题上产生“乐观偏差（Lookahead / Optimism Bias）”。
  - 事件驱动引擎（如 NautilusTrader）高度拟真实盘排队时延、状态机转换与订单生命周期，但配置繁琐、参数遍历效率较低。
- **对齐准则**：
  **以 VectorBT PRO 运行全样本 WFO、蒙特卡洛 10,000 次模拟及多维参数敏感性探索；以 NautilusTrader 运行逐笔事件级订单对齐验证。实盘部署与生产网关完全依托 NautilusTrader 原生运行。**

### 8.2 严格交易成本与名义敞口结算模型
回测必须与实盘账户严格对齐，彻底杜绝“零手续费下的纸上富贵”：

1. **计费基准**：
   - 开仓与平仓手续费必须基于**名义价值（Notional Value）**计算，而非保证金：
     $$\text{Notional} = \text{Contracts} \times \text{ContractValue} \times \text{ExecutionPrice}$$
     $$\text{Fee} = \text{Notional} \times \text{FeeRate}$$
2. **费率配置**：
   - **Maker 费率**：$0.02\%$（2.0 bps，限价单挂单成交）。
   - **Taker 费率**：$0.05\%$（5.0 bps，市价单吃单成交）。
   - **入场与加仓**：按 Taker $0.05\%$ 结算（市价单开仓对齐实盘当前配置）。
   - **止盈与止损**：按 Taker $0.05\%$ 结算（触发条件单后市价强平）。
3. **滑点模型（Slippage Injection）**：
   - 基础回测计入 $1.0\text{ bps}$ 撮合滑点；
   - 压力测试注入 $3.0 \sim 5.0\text{ bps}$ 极端流动性滑点。
4. **资金费率（Funding Rate, 估算计提）**：
   - 平均持仓周期超过 8 小时的头寸，每跨越一个结算周期（UTC 00:00, 08:00, 16:00），按基准 $0.01\%$ 扣减名义持仓资金费。

## 9. 顶级量化对冲基金三层 AI 哨兵监控体系 (Surveillance Sentinel)

在生产环境中，交易程序绝不能成为无监管的孤岛。必须启动一个独立的监控看门狗进程（`ai_sentinel_monitor.py`），通过异步套接字监听行情与成交，执行三级阻断保护。

```mermaid
stateDiagram-v2
    [*] --> Normal_Running: 系统就绪, 仓位管理正常
    
    Normal_Running --> Warning_State: 触发预警 (胜率<70% OR 滑点>5bps)
    Warning_State --> Normal_Running: 机制回归正常
    
    Warning_State --> Frozen_State: 触发硬熔断 (连损3笔 OR 胜率<65% OR ATR倍数>2.5)
    Normal_Running --> Frozen_State: 发生极端踩踏或突发穿仓
    
    state Frozen_State {
        [*] --> Cancel_All_Orders: 撤销全部未成交挂单
        Cancel_All_Orders --> Market_Flatten: 启动市价平仓锁定风险
        Market_Flatten --> Lock_Trading_48H: 封锁交易网关48小时
        Lock_Trading_48H --> Trigger_Retrain_Pipeline: 调度云端/本地 JIT 重训
    }
    
    Frozen_State --> Normal_Running: 新策略通过四大出厂门禁, 校验成功解除封锁
```

### 9.1 L1 微观执行层（Slippage, Latency, Fill Ratio）
- **滑点哨兵（Slippage Auditor）**：
  $$\text{Slippage(bps)} = \frac{|\text{FillPrice} - \text{ExpectedPrice}|}{\text{ExpectedPrice}} \times 10,000$$
  若单笔滑点 $> 5.0\text{ bps}$，立即向管理员群发送执行风险警告，并自动将加仓比例从 75% 降级至 35%。
- **时延与网络审查**：
  监控从 BarClose 事件产生到订单回报 ACK 的往返延迟（Round-trip Latency）。若延迟 $> 800\text{ ms}$，记录异常日志并告警。

### 9.2 L2 因子与概念漂移层（Concept Drift & Market Regime Shift）
- **双样本柯尔莫哥洛夫-斯米尔诺夫检验 (Two-Sample K-S Statistical Drift Test)**：
  在 MLOps 持续训练 (Continuous Training, CT) 范式下，系统通过对过去 200 根运行期 K 线的特征分布（如 Rolling Z-Score, Parkinson 波动率）与 In-Sample 基准特征分布执行双样本 K-S 显著性检验：
  $$D_{n, m} = \sup_x |F_{1, n}(x) - F_{2, m}(x)|$$
  当双尾 $p$-value $< 0.01$ 时，判定底层资产微观数据分布发生显著漂移（Data Drift），系统自动亮起橙灯报警并调度重训进程。
- **滚动胜率下限（Rolling Win Rate Floor）**：
  监控最近 20 笔平仓交易。胜率基准为 $75\% \sim 90\%$。
  - 预警线：滚动胜率 $< 70\%$；
  - **熔断线：滚动胜率 $< 65\%$**。一旦跌破，判定微观规律老化，触发自适应重训。
- **市场年化波动率跃迁告警（Volatility Explosion Guard）**：
  计算最近 30 天年化波动率 $\sigma_{\text{30d}}$ 与基准历史 365 天年化波动率 $\sigma_{\text{baseline}}$：
  $$\text{Vol\_Ratio} = \frac{\sigma_{\text{30d}}}{\sigma_{\text{baseline}}}$$
  当 $\text{Vol\_Ratio} > 2.5$ 时，判定以太坊进入非理性高波踩踏机制，原固定通道参数彻底失效，系统强制停止新开仓并请求重训。
- **单边强趋势持久度检测（Persistent Trend Sentinel）**：
  若价格在连续 48 根 15m K线（12小时）内单边位于 SMA50 同侧且无反向回踩突破，判定为“流动性踩踏单边市”，系统动态将首仓比例收紧至 $25\%$，并拉宽加仓距离。

### 9.3 L3 资本与组合硬熔断层（Circuit Breaker）
- **连续亏损硬熔断（Consecutive Loss Breaker）**：
  **连续 3 笔平仓触发硬止损，策略无条件进入紧急冷冻熔断状态！** 立即撤销所有挂单，封锁任何新开仓权限 48 小时。
- **最大组合回撤硬熔断（Max Portfolio Drawdown Breaker）**：

## 11. 扩展架构：未来混合机器学习组件体系 (LightGBM & Pure-NumPy Transformer)

为满足未来策略向多因子深度学习扩展的需求，系统预留两大轻量化通用机器学习模板。

### 11.1 工业级梯度提升树：LightGBM + PurgedGroupTimeSeriesSplit
- **应用场景**：作为 AST 符号树的外层宏观机制过滤器（Regime Filter），预测未来 4 根 K 线（1小时）的大波动概率。
- **数据无泄漏切分标准**：
  采用去重叠（Purged）与防信息渗透（Embargo）的时序交叉验证，严格隔离两笔持仓时间重叠的样本标签。

```python
import lightgbm as lgb
from sklearn.model_selection import TimeSeriesSplit

def train_lgb_regime_filter(X, y):
    """
    轻量化 GBDT 宏观机制过滤器
    目标：预测未来波动率爆发概率，输出 [0, 1] 概率控制首仓大小
    """
    params = {
        'objective': 'binary',
        'metric': 'auc',
        'boosting_type': 'gbdt',
        'learning_rate': 0.03,
        'num_leaves': 31,
        'feature_fraction': 0.8,
        'bagging_fraction': 0.8,
        'bagging_freq': 5,
        'verbose': -1,
        'n_jobs': -1
    }
    
    tscv = TimeSeriesSplit(n_splits=5)
    models = []
    
    for train_idx, val_idx in tscv.split(X):
        X_train, y_train = X.iloc[train_idx], y.iloc[train_idx]
        X_val, y_val = X.iloc[val_idx], y.iloc[val_idx]
        
        dtrain = lgb.Dataset(X_train, label=y_train)
        dval = lgb.Dataset(X_val, label=y_val, reference=dtrain)
        
        model = lgb.train(
            params,
            dtrain,
            num_boost_round=500,
            valid_sets=[dtrain, dval],
            callbacks=[lgb.early_stopping(stopping_rounds=30, verbose=False)]
        )
        models.append(model)
        
    return models
```

### 11.2 Pure-NumPy Micro-Transformer 极致轻量因果注意力模型
- **应用场景**：在微型容器或边缘端运行，提取最近 32 根 K 线的时序因果注意力表征，不依赖庞大的 PyTorch/TensorFlow 运行时环境，仅依靠 NumPy 矩阵运算在 0.2 毫秒内完成推断。

```python
import numpy as np

class PureNumpyCausalAttention:
    """
    纯 NumPy 实现的单头因果自注意力机制 (Causal Self-Attention)
    零外部深度学习框架依赖，微秒级推断
    """
    def __init__(self, d_model: int):
        self.d_model = d_model
        # 预先固定或由云端导出的权重矩阵
        self.W_q = np.random.randn(d_model, d_model) * 0.05
        self.W_k = np.random.randn(d_model, d_model) * 0.05
        self.W_v = np.random.randn(d_model, d_model) * 0.05
        self.scale = 1.0 / np.sqrt(d_model)

    def forward(self, x: np.ndarray) -> np.ndarray:
        """
        x 形状: (T, d_model)
        """
        T, d = x.shape
        Q = np.dot(x, self.W_q) # (T, d)
        K = np.dot(x, self.W_k) # (T, d)
        V = np.dot(x, self.W_v) # (T, d)

        # 计算点积注意力得分: (T, T)
        scores = np.dot(Q, K.T) * self.scale

        # 构造因果下三角掩码 (Causal Mask, 防未来穿越)
        mask = np.triu(np.ones((T, T)), k=1).astype(bool)
        scores[mask] = -1e9

        # Softmax 归一化
        exp_scores = np.exp(scores - np.max(scores, axis=-1, keepdims=True))
        attn_weights = exp_scores / np.sum(exp_scores, axis=-1, keepdims=True)

        # 加权输出: (T, d_model)
        out = np.dot(attn_weights, V)
        return out
```
